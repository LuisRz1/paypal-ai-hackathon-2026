## Estrategia

1. Elige **un** sponsor con premio y úsalo a fondo. La regla permite máximo un sponsor prize.
2. AG Grid es el de mayor valor esperado (5 premios) y el jurado premia pulido + Agent Framework.
3. Bryntum tiene solo 2/100 repos usándolo: menos competencia, 3 premios.
4. Channel3 tiene 1 premio, pero un demo muy claro y diferenciable.
5. APIMatic se puede usar “gratis” para desarrollar y documentar; no compite con el sponsor principal.
6. Render es casi obligatorio para hospedar; sus créditos son un extra.
