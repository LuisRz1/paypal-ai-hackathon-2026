# Otros sponsors

## APIMatic

- **Qué:** Context Plugins para agentes de código; SDKs y portales generados desde OpenAPI.
- **Oferta:** 1 mes Basic gratis para participantes; 6 meses Business para ganadores.
- **Premio:** $1,000 ×3 + 6 meses Business.
- **Uso:** dar contexto PayPal a Claude Code/Cursor, generar SDK tipado, auditar la integración.
- **Enlace:** https://paypalaihackathon.devpost.com/details/apimatic

## Astropods

- **Qué:** “Agent OS”: modelos, knowledge bases, tools, observabilidad, runtime y guardrails.
- **Oferta:** cuenta gratis; deploy por CLI/API/dashboard.
- **Premio:** no tiene premio propio.
- **Uso:** correr el agente en producción con observabilidad.
- **Enlace:** https://paypalaihackathon.devpost.com/details/astropods

## Elastic

- **Qué:** Elasticsearch; búsqueda híbrida/vectorial, ES|QL, Agent Builder, Workflows, MCP/A2A.
- **Oferta:** trial 14 días + extensión 30 días; o local gratis.
- **Premio:** no tiene premio propio.
- **Uso:** memoria/retrieval del agente sobre transacciones, disputas o catálogo.
- **Enlace:** https://paypalaihackathon.devpost.com/details/elastic

## KERNEL

- **Qué:** navegadores cloud para agentes: <30 ms, anti-bot, live view y replay, auth durable.
- **Oferta:** $50 con `KERNELDEVPOST2026`.
- **Premio:** no tiene premio propio.
- **Uso:** agente que opera el checkout web o portales de merchant.
- **Enlace:** https://paypalaihackathon.devpost.com/details/kernel
