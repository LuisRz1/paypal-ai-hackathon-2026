# Channel3

## Qué es

Una API que devuelve datos de producto limpios y normalizados — título, imágenes, precios, variantes, disponibilidad y buy links — sobre **100M+ productos de 25,000+ retailers**. Sin scraping ni feeds.

Se usa para shopping agents, gift finders, AI stylists, comparadores y búsqueda conversacional.

## Oferta

- API keys para todos los participantes.
- **20,000 créditos gratis** con el código `PAYPAL-HACKATHON-2026`.
- Si se acaban, se puede pedir top-up en Discord.
- Premio: **$1,500**.
- Jurado: Ignacio Valdez Bicard (Founding Engineer).

## Requisito del premio

- El proyecto debe **usar la API o el MCP server** de forma significativa: búsqueda, enriquecimiento o recomendaciones.
- Solo mencionar Channel3 no cuenta.

## Cómo integrarlo

- Sign up: https://trychannel3.com/developers
- Docs: https://docs.trychannel3.com
- MCP: https://trychannel3.com/mcp
- Key en dashboard; no requiere tarjeta.

## Ideas

- Agente que busca un producto, compara variantes y paga con PayPal.
- Gift finder conversacional con presupuesto.
- “AI stylist” que arma un outfit y hace checkout.
- Comparador de precios entre retailers con link de compra.
- Storefront donde el agente negocia y el humano aprueba.

## Riesgos

- Espacio de shopping agents muy poblado (~16/100 repos).
- El premio es uno solo; la competencia es alta.
- Necesitas una historia de confianza: límites de gasto, aprobación humana y verificación del pedido.
