# Glosario

| Término | Definición |
|---|---|
| **Authorization** | Retención de fondos sin cobro; válida hasta 29 días |
| **Capture** | Cobro efectivo de una autorización u orden |
| **Void** | Cancelación de una autorización antes de capturar |
| **Reauthorize** | Extender una autorización existente |
| **Refund** | Devolución total o parcial de una captura |
| **APM** | Alternative Payment Method (iDEAL, Bancontact, etc.) |
| **BNPL** | Buy Now, Pay Later (Pay Later) |
| **Dispute** | Reclamación del comprador; interna o externa |
| **Chargeback** | Reversión iniciada por el banco/emisor |
| **ACH return** | Devolución iniciada por el banco |
| **Pre-chargeback alert** | Aviso previo a un chargeback; 20 h para reembolsar |
| **INR** | Item Not Received |
| **SNAD** | Significantly Not As Described |
| **Webhook** | Callback HTTPS de PayPal a tu servidor |
| **Idempotency** | Repetir una operación sin duplicar el efecto |
| **Reconciliation** | Comparar y corregir estado local contra PayPal |
| **Read-back** | Releer el recurso en PayPal para verificar |
| **Ledger** | Registro append-only de eventos y acciones |
| **Agent Toolkit** | Librería de tools PayPal para function calling |
| **MCP** | Model Context Protocol |
| **x402** | Protocolo de pagos agente-a-agente (no PayPal) |
| **AG Studio** | Dashboard/grid/charts embebido de AG Grid |
| **Studio Agent Framework** | Framework de agentes para AG Studio |
| **Bryntum Gantt** | Componente de timeline con dependencias |
| **Channel3** | API de datos de producto normalizados |
| **Sandbox** | Entorno de pruebas de PayPal con dinero ficticio |
| **Negative testing** | Forzar errores en sandbox |
| **Access token** | Token OAuth para llamar APIs |
| **Client ID / Secret** | Credenciales de la app PayPal |
| **Merchant of record** | Vendedor responsable de la transacción |
